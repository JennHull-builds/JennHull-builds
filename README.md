### Senior Product Designer & Design Engineer

I design products and build their front ends. Most of what I build now has AI in it: [an agent system that runs my working day](https://jenniferhull.co.za/blog/the-mothership-runs-the-radar), with its own evals; pipelines that check model output before anything uses it; and design systems that AI coding tools can read.

* **Public builds:**
  * [`dx-grid-inspector`](https://github.com/JennHull-builds/dx-grid-inspector): inspect a live React UI, calibrate its radius, padding and colour tokens, and copy them out as CSS, JSON or an agent prompt. [On npm](https://www.npmjs.com/package/dx-grid-inspector).
  * [`tetherlog`](https://github.com/JennHull-builds/tetherlog): a capture app for neurodivergent brains, with an AI evening review whose output is checked against a schema. [Live](https://tetherlog-rouge.vercel.app).
  * [`nil-ds`](https://github.com/JennHull-builds/nil-ds): a token and component kit, 20 components, each with its own tests. [Showroom](https://nil-ds.vercel.app).
